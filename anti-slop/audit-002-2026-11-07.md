# Anti-Slop Audit Report #002

- **Date:** 2026-11-07
- **Target:** `app/page.tsx`, `components/ui/ntb-glyph-hero.tsx`, `components/ui/glyph-portal.tsx`
- **Audit Mode:** Mode 2 (After)

## Audit Summary

Audit terhadap integrasi komponen `GlyphPortal` ("NUSA TENGGARA BARAT") dan penyesuaian narasi konten keberagaman NTB (Lombok & Sumbawa, budaya Sasambo).

## Numbered Findings List

| # | Priority | Rule | Violated Pattern & Finding | Reason |
|---|---|---|---|---|
| 1 | **LOW** | R-21 | Tema halaman masih menggunakan palet gelap paten (`bg-[#120a06]`) belum dilengkapi *light mode toggle*. | Desain mengandalkan mode gelap tanpa tombol pengubah tema dinamis. |
| 2 | **LOW** | R-06 | Penggunaan jenis huruf bawaan sistem (*system sans*) dan Arial Black untuk live-type canvas. | Membutuhkan font display berkarakter khas nusantara untuk memperkuat kepribadian Bumi Gora. |

---

## Checklist Evaluasi Aturan Inti (Hard Gate & Purpose-Gate)

- [x] **R-02 (Copywriting):** Bebas karakter em dash (`—`) di seluruh teks UI yang baru ditambahkan.
- [x] **R-03 (Mobile Responsiveness):** Tidak ada *horizontal overflow*. Skala huruf SVG otomatis disesuaikan dengan lebar kontainer via kalkulasi `bounds.width` dan `startScale`.
- [x] **R-04 (Icons):** Ikon relevan menggunakan `lucide-react` (`Mountain` untuk Rinjani & Tambora, `Waves` untuk Teluk Saleh & Gili, `Landmark` untuk Istana Dalam Loka, `Flame` untuk Main Jaran).
- [x] **R-17 & R-36 (Honest Data):** Data faktual (elevasi Rinjani 3.726 mdpl, Tambora 2.851 mdpl, 2 Pulau Utama, 2 Geopark UNESCO, 3 Etnis Sasambo).
- [x] **R-24 & R-26 (Navigation & Controls):** Seluruh tautan navigasi (`#portal`, `#tentang`, `#galeri`, `#destinasi`, `#budaya`) memiliki jangkar tujuan nyata. Dialog modal terbuka dan tertutup dengan tombol Escape serta tombol tutup.
- [x] **R-25 (Contrast):** Kontras teks memenuhi standar WCAG AA (warna teks `#fff4e8` di atas latar `#120a06` dan `#180f08`).
- [x] **R-32 & R-39 (Accessibility):** Navigasi keyboard penuh (`Tab`, `Space`, `Enter`, `Escape`), tombol radio pemilihan karakter memiliki `aria-label`, dialog memiliki `aria-modal="true"`.
