# Anti-Slop Audit Report #003

- **Date:** 2026-11-11
- **Target:** `app/page.tsx`, `components/ui/demo.tsx`, `components/ui/glyph-portal.tsx`, `components/ui/zoom-parallax.tsx`, `components/ui/ridgeline-dither-footer.tsx`
- **Audit Mode:** Mode 2 (After)
- **Scope:** Cross-device smoothness risks visible from source. No device profiling was performed.

## Numbered Findings List

| # | Priority | Rule | Finding | Reason |
|---|---|---|---|---|
| 1 | **MEDIUM** | C-4 | Hero depends on a remotely hosted WOFF2 font and runs a canvas text measurement/paint animation in `GlyphPortal`; it also uses a long scroll-driven zoom. | Network latency, mobile GPU limits, and font loading behavior can make the main interaction feel stalled or uneven on non-Apple devices. |
| 2 | **MEDIUM** | C-4 | The page combines the interactive hero with a 300vh parallax section and a continuously animated canvas in the footer. | These effects add sustained paint/compositing work and may expose performance gaps on lower-powered Android and Windows hardware. |
| 3 | **LOW** | C-4 | Several visual layers rely on `backdrop-filter` and large transforms/blur effects, including navigation and destination cards. | Support exists in modern browsers, but implementation cost and frame rate vary by browser, GPU, and device; a fallback does not guarantee equivalent smoothness. |
| 4 | **MEDIUM** | R-03 / C-4 | In `components/ui/demo.tsx`, the wrapper declares `containerType: "inline-size"`, but its `@container(max-height:479px)` rule queries the container's height. | An inline-size query container does not provide a queryable block size, so the short-viewport adjustments for the header, caption, and support copy may not apply consistently. |
| 5 | **MEDIUM** | C-4 | `ZoomParallaxDemo` creates a Lenis instance on mount and drives its RAF loop continuously; that instance smooths wheel input across the window while Framer Motion also tracks scroll for the parallax. | This is a concrete candidate for wheel-scroll feeling delayed or uneven on Windows. Lenis defaults to native touch scrolling (`syncTouch: false`), so it does not by itself explain Android touch behavior. |
| 6 | **MEDIUM** | C-4 | The gallery animates seven image layers up to 4x–9x scale and loads remote Unsplash images. | Large composited layers and image decode work can drop frames on Android devices with limited GPU or memory. |

## Limits

Source review identifies likely pressure points, not a confirmed production failure. The production URL could not be loaded by the available page inspection tool. A browser/device reproduction with versions and a precise location in the page is still needed to separate layout issues from dropped frames.
